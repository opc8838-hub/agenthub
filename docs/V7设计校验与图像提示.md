# V7 设计校验与图像提示

## 视觉方向

- 纸张米白、墨黑、科技蓝为主色，蓝紫渐变只承担重点与路径表达。
- 所有主题使用同一套纸塑编辑插画语言，但每屏拥有独立隐喻。
- 删除统一椭圆、光圈与图片说明文字，插图本身承担叙事。
- 标题保持黑色重量，核心结果词使用蓝紫渐变，保证远距离阅读和视觉节奏。

## 最终图像提示策略

使用内置图片生成工具，统一基础提示为：保留 T-agent 的白色圆润身体、黑色面罩、两枚白色竖眼、蓝色天线球和蓝色 T 标记；使用高级编辑式纸塑与克制的软 3D 质感；墨黑、暖白、钴蓝和少量蓝紫渐变；必须为真实透明背景；禁止装饰圆环、光环、说明文字、水印、儿童绘本感和塑料玩具感。

各主题的独立提示：

1. 社区介绍：T-agent 以开放姿态连接人才节点、产品方块和工厂，蓝紫路径从人才流向产业。
2. 长期计划：T-agent 架起企业与社区之间的桥梁，表达“AI 走进企业，真实问题回到社区”。
3. 负责人 / 主讲老师：从业务蓝图、系统模块到向上产品路径，表达将想法做成产品。
4. 课程成长路线：从鼠标指针、工作流节点走向完成的产品方块，表达从入门到作品。
5. AI 实战社群：三条开放知识流分别传递资讯、工具和模板，不形成闭环或圆圈。
6. 产品与定制开发：网站、Agent 核心和工作流模块拼合成一套可工作的产品系统。
7. 咨询与 1V1 陪跑：多条混乱路径经过共同判断后汇成一条明确路线并抵达目标。

## 自检评分

整体：**8.9 / 10**

- 方向一致性：9.1 — 文案、色彩和插图都围绕“AI 从创意走向落地”。
- 视觉层级：9.0 — 主题标题、价值句、细节和行动按钮四级清晰。
- 工艺质量：8.7 — 宽度、字号、间距和插图语言统一，透明边缘与响应式正常。
- 功能有效性：9.2 — 每张图都有具体关系隐喻，没有无功能的统一装饰。
- 原创辨识度：8.6 — T-agent 与东莞产业落地叙事形成专属识别，未套用通用 SaaS 卡片模板。

## 技术校验

- 7 个主题、7 个蓝紫文字重点、7 张 V3 插图全部加载。
- 7 张插图全部为 RGBA 真透明图片。
- 插图容器的 `::before` / `::after` 装饰圆环已关闭。
- 9 个弹窗、目录滚动、键盘焦点与关闭逻辑通过。
- 320、375、390、768、1024 与 1440px 宽度下无横向溢出。
- 浏览器无 JavaScript 错误。
