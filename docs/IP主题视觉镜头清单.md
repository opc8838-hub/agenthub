# T-agent 主题视觉镜头清单

所有图片用于网页大屏的主题配图，主标题由 HTML 排版，图片内部不生成文字、字母、数字或水印。统一采用 1:1 解释型插图，保留 T-agent 的扁平手绘造型、粗黑轮廓、黑白主色、蓝紫色天线和胸前 T 标记。

## 02 长期计划

- concrete_claim：长期进入企业现场，并把真实业务问题连接给 AI 实践者持续解决。
- relation：连接与循环。
- visual_metaphor：T-agent 亲手搭起一座连接工厂与 AI 创作工坊的桥；真实问题从工厂一端进入，解决方案从另一端返回。
- ip_action：T-agent 位于桥中央，正在扣紧最后一段连接结构。
- references：角色总览 + 行动姿态。

## 04 课程成长路线

- concrete_claim：零基础学习者可以沿着清晰路径，从认识 AI 走到做出自己的产品。
- relation：成长旅程。
- visual_metaphor：T-agent 沿三块逐渐升高的大台阶前进，依次跨过问号、工具箱和发光作品原型。
- ip_action：T-agent 抱着刚完成的作品踏上最高一级。
- references：角色总览 + 思考姿态 + 灵感姿态。

## 05 AI 实战社群

- concrete_claim：成员每天都能获得资讯、工具、答疑和可复用资源的持续补给。
- relation：补给与共享。
- visual_metaphor：T-agent 运营一座开放的 AI 补给站，把新闻、Skill 工具、模板和答疑分别放入同一个持续运转的资源环。
- ip_action：T-agent 正把新工具放上资源环，并把现成模板递给使用者。
- references：角色总览 + 确认姿态 + 友好互动姿态。

## 06 产品与定制开发

- concrete_claim：把模糊的业务需求转化成真正可使用的网站、Agent、工作流和 SaaS。
- relation：输入到输出的转化。
- visual_metaphor：一张简洁的业务需求草图进入 T-agent 的产品工作台，另一端产出一个完整可运行的数字产品。
- ip_action：T-agent 操作工作台完成组装，亲手点亮最终产品。
- references：角色总览 + 灵感姿态 + 行动姿态。

## 07 咨询与 1V1 陪跑

- concrete_claim：从看不清问题到获得明确路径，并有人陪着持续推进。
- relation：引导与同行。
- visual_metaphor：起点是一团混乱路线，终点是清晰目标；T-agent 手持指南针陪伴一个抽象人物沿正确路径前进。
- ip_action：T-agent 一边校准方向，一边带领对方跨过关键节点。
- references：角色总览 + 思考姿态 + 确认姿态。
